Sachen, Standorte, Einzelobjekte

Im Inventar gibt es drei Dinge: Sachen (was es gibt), Standorte (wo etwas ist) und Einzelobjekte (dieses eine Gerät mit eigenem Label). Diese Seite zeigt, wie sie zusammenhängen.

Auf einen Blick

{% icon "boxes" %}Eine Sache ist eine allgemeine Beschreibung eines Gegenstands mit Name, Fotos und Beschreibungstext, zum Beispiel „Acrylfarbe Weiß“, „Teelichter“ oder „Nähmaschine“. Jede Sache wird auf eine von zwei Arten geführt:

Als Mengenartikel

Uns interessiert nicht der einzelne Nagel oder die einzelne Rolle Nähgarn. Es zählt nur, wie viel davon wo liegt: je Standort ein Bestandseintrag mit Menge. Dieselbe Sache kann an vielen Standorten liegen.

Mit Einzelobjekten

{% icon "geo-alt" %} Standort

Alles, worin oder worauf etwas sein kann. Standorte stecken ineinander und haben einen kurzen Code wie R411. Es gibt drei Sorten:

  • {% icon "geo-alt" %}Gebäudeteil: Ebene, Raum, Bereich. Bewegt sich nie.
  • {% icon "bookshelf" %}Lagermöbel: Regal, Schrank, mit ihren Fächern und Schüben.
  • {% icon "eurobox-open" %}Behälter: Kiste, Karton, Palette. Zieht mit dem Inhalt um.

Menge oder Einzelobjekt

Die beiden Arten im Vergleich. Eine Sache ist immer nur eins von beiden.

Was alle Einzelobjekte einer Sache gemeinsam haben (Beschreibung, Fotos, Dateien, Einweisungspflicht), steht einmal bei der Sache. Die Art lässt sich nur ändern, solange die Sache weder Bestand noch Einzelobjekte hat.

Die {{ label_id_name }}

Jedes Einzelobjekt trägt ein kleines Label mit QR-Code und seiner {{ label_id_name }}, einer kurzen Kennung wie K7R-4XD.

  • {% icon "qr-code-scan" %}Scannen öffnet die Seite genau dieses Geräts: wo es hingehört, wer sich darum kümmert und ob man eine Einweisung braucht.
  • {% icon "search" %}Eintippen geht auch: die {{ label_id_name }} in die Suche eingeben. Bindestrich, Groß- und Kleinschreibung und Verwechsler wie O und 0 sind egal.
  • {% icon "tag" %}Für immer. Eine {{ label_id_name }} gehört nur zu ihrem Gerät und wird nie an ein anderes vergeben, auch nicht, wenn es ausgemustert ist.
  • {% icon "box-star" %}Auch für Leihgaben. Geräte, die jemandem gehören und dem ZAM geliehen sind, bekommen ebenfalls eine {{ label_id_name }}. So ist klar, wem sie gehören.
{% icon "exclamation-triangle" %}

Das Label bitte nie entfernen. Ohne {{ label_id_name }} ist ein Gerät nur noch irgendeine Nähmaschine. Niemand sieht dann mehr, welche es ist, wohin sie gehört, wer sie betreut, ob man eine Einweisung braucht und bei einer Leihgabe, wem sie gehört.

Also nicht abziehen, nicht überkleben und nie auf ein anderes Gerät umkleben. Ist ein Label abgegangen oder unleserlich, sag dem zuständigen Team Bescheid oder drucke es auf der Seite des Einzelobjekts neu. Ein loses Label nicht wegwerfen: Scannen zeigt, wohin es gehört.

Standorte stecken ineinander

Jeder Standort liegt in einem anderen: der Karton im Fach, das Fach im Schrank, der Schrank in der Werkstatt, die Werkstatt auf einer Ebene. Oben in jeder Standortseite steht dieser Pfad.

{% include "inventory/help/_example_tree.html" %}

Sachen und Einzelobjekte können bei jedem Standort im Pfad sein, nicht nur ganz innen im Karton. Die Nähmaschine Paula steht direkt im Fach S140.b, neben dem Karton. Und die Acrylfarbe, die frei in der Farbwerkstatt steht, ist direkt beim Bereich FW eingetragen.

Gebäudeteil, Lagermöbel, Behälter

Jeder Standort hat einen Standorttyp. Der Typ legt fest, wie der Code aussieht, ob der Standort umziehen kann und ob weitere Standorte hineinpassen. Die Typen gehören zu drei Kategorien.

{% include "inventory/help/_type_cards.html" %}

Was worin stehen kann

Die übliche Kette von außen nach innen: Ebene › Raum oder Bereich › Regal oder Schrank › Fach oder Schub › Kiste oder Karton. Abkürzungen sind erlaubt: Eine Kiste darf auch direkt im Raum oder auf der Ebene stehen.

Codes lesen

Der Code steht auf dem Label am Standort und führt per Scan oder Suche direkt hin. Es gibt zwei Sorten.

Ka00410

Eigener Code. Gebäudeteile mit eigenem Namen, Regale, Schränke, Paletten, Kisten und Kartons haben einen Code, der hausweit nur einmal vorkommt. Er sagt nichts über den Ort darüber. Darum bleibt er gleich, wenn der Karton umzieht.

S140.b

Abgeleiteter Code. Fächer, Schübe, Teilräume und Teilbereiche gibt es nur als Teil von etwas. Ihr Code ist der Code darüber, ein Punkt und ein Buchstabe oder eine Nummer: Fach b im Schrank S140. Fächer und Schübe zählen immer von unten nach oben, b ist also das zweite von unten. Regale und Schränke selbst sind im Raum normalerweise von links nach rechts nummeriert.

HH+0

Ebenen tragen Haus und Ebene mit Vorzeichen: WH Werkhaus, HH Haupthaus; 0 liegt ebenerdig zur Hauptstraße. Das Vorzeichen steht immer da, damit ein verlorenes Minus nicht zur falschen Ebene führt.

Einmal vergebene Codes bleiben beim Standort. Ein alter Code führt auch nach einer Umbenennung noch zum richtigen Ort. Einzelobjekte haben statt eines Standortcodes ihre {{ label_id_name }}.
