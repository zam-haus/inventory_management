Items, locations, unique items

The inventory knows three things: items (what there is), locations (where something is) and unique items (this one device with its own label). This page shows how they fit together.

At a glance

{% icon "boxes" %}An item is a general description of a thing with a name, photos and a description, for example “white acrylic paint”, “tea lights” or “sewing machine”. Every item is kept in one of two ways:

As a bulk item

We don't care about the single nail or the single reel of thread. All that counts is how much of it is where: one stock entry with an amount per location. The same item can be at many locations.

With unique items

There can be several of one item, say the sewing machine model A38. We still want to tell them apart, because when one breaks, it matters which one it was. So every unique item has its own {{ label_id_name }} and exactly one location.

{% icon "geo-alt" %} Location

Anything something can be in or on. Locations sit inside one another and have a short code like R411. There are three sorts:

  • {% icon "geo-alt" %}Space: level, room, area. Never moves.
  • {% icon "bookshelf" %}Storage unit: shelf, cabinet, with their compartments and drawers.
  • {% icon "eurobox-open" %}Container: box, carton, pallet. Moves with its contents.

What all unique items of an item share (description, photos, files, required briefing) is kept once with the item. The kind can only be changed while the item has neither stock nor unique items.

The {{ label_id_name }}

Every unique item carries a small label with a QR code and its {{ label_id_name }}, a short ID like K7R-4XD.

{% include "inventory/help/_label_mockup.html" %}
  • {% icon "qr-code-scan" %}Scanning opens the page of exactly this device: where it belongs, who looks after it and whether you need a briefing.
  • {% icon "search" %}Typing works too: enter the {{ label_id_name }} in the search. Hyphen, capitals and look-alikes such as O and 0 don't matter.
  • {% icon "tag" %}Forever. A {{ label_id_name }} belongs to its device only and is never given to another one, not even when it has been retired.
  • {% icon "box-star" %}Loans too. Devices that belong to someone and are lent to the ZAM get a {{ label_id_name }} as well. That makes clear whose they are.
{% icon "exclamation-triangle" %}

Please never remove the label. Without its {{ label_id_name }} a device is just some sewing machine. Nobody can tell any more which one it is, where it belongs, who looks after it, whether you need a briefing and, for a loan, whose it is.

So don't peel it off, don't cover it and never move it to another device. If a label has come off or can't be read, tell the team in charge or print it again on the unique item's page. Don't throw a loose label away: scanning it shows where it belongs.

Locations sit inside one another

Every location is inside another one: the carton in the compartment, the compartment in the cabinet, the cabinet in the workshop, the workshop on a level. This path is shown at the top of every location page.

Items and unique items can be at any location along the path, not only innermost in the carton. The sewing machine Paula stands directly in compartment S140.b, next to the carton. And the acrylic paint standing loose in the paint workshop is entered directly at the area FW.

Space, storage unit, container

Every location has a location type. The type decides what the code looks like, whether the location can move and whether further locations fit inside. The types belong to three categories.

What goes where

The usual chain from the outside in: level › room or area › shelf or cabinet › compartment or drawer › box or carton. Shortcuts are allowed: a box may also stand directly in a room or on a level.

Reading codes

The code is on the label at the location and leads straight to it by scan or search. There are two sorts.

Ka00410

Own code. Spaces with a name of their own, shelves, cabinets, pallets, boxes and cartons have a code that occurs only once in the whole building. It says nothing about the place above it. That's why it stays the same when the carton moves.

S140.b

Derived code. Compartments, drawers, sub-rooms and sub-areas exist only as part of something. Their code is the code above, a dot and a letter or number: compartment b in cabinet S140. Compartments and drawers always count from the bottom up, so b is the second from the bottom. Shelves and cabinets themselves are usually numbered from left to right in the room.

HH+0

Levels carry building and level with a sign: WH Werkhaus, HH Haupthaus; 0 is at street level of the main road. The sign is always there, so a lost minus never leads to the wrong level.

Codes stay with their location once given. An old code still leads to the right place after a rename. Unique items have their {{ label_id_name }} instead of a location code.
