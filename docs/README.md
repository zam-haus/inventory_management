# Documentation

How the ZAM inventory works, feature by feature. Setup and deployment are
covered in the [project README](../README.md).

* [Concepts](concepts.md): bulk items vs. unique items, locations, initial data collection
* [Location summaries](locations.md): overview photo, summary line and change history
* [Quick-items](quick-items.md): items known only by name, edited in the location list
* [Stock changes](stock-changes.md): the 🛒 dialog and the stock change log
* [Unique items](unique-items.md): single objects (*Einzelobjekte*) with their own ZAM ID, owner and history
* [ZAM IDs](zam-ids.md): permanent label IDs, resolver, lifecycle and label PNGs
* [Camera scanning](camera-scanning.md): QR and barcode scanning in the browser
* [Permissions](permissions.md): model permissions, the ZAM-local group and network detection
* [Label printing](label-printing.md): MQTT print server for location labels
* [Favicon](branding/README.md): source design and how the served icons are derived
